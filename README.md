## Overview

A personal portfolio website to showcase my information, projects, and professional background. The website is built with a modern tech stack and features a clean, responsive design with both dark and light mode themes.

## Technologies

- **Framework:** Next.js 14
- **UI Library:** React 18
- **Component Library:** Chakra UI
- **Animations:** Framer Motion
- **Icons:** React Icons
- **Code Quality:** ESLint, Prettier

## Features

- Responsive design that works on all devices
- Dark and light mode themes
- Smooth animations and transitions
- Project showcase section
- About me section
- Contact information
- Modern UI with Chakra UI components

## The Process

1. **Planning** - Designed the structure and layout for the personal website
2. **Setup** - Initialized Next.js project with Chakra UI integration
3. **Development** - Built components for Header, Projects, About, and more
4. **Styling** - Applied custom theming with dark/light mode support
5. **Animations** - Added Framer Motion animations for smooth interactions
6. **Testing** - Verified responsiveness and functionality

## Running the Project

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run linter
npm run lint

# Format code
npm run prettier
```

The development server runs on `http://localhost:3000` by default.
